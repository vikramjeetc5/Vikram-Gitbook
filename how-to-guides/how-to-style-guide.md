# How-to Style Guide

This page sets the writing and formatting rules for the VC Technologies documentation portal. Follow it when you add or edit a page, so every page looks and reads the same way.

| Owner         | Document type | Version | Last updated    |
| ------------- | ------------- | ------- | --------------- |
| IT Department | Style guide   | 1.0     | 29 October 2026 |

### Writing Rules

| Topic           | Rule                                         | Example                                                    |
| --------------- | -------------------------------------------- | ---------------------------------------------------------- |
| Tone            | Plain, direct, and polite                    | "Select **Connect**." not "You may wish to click Connect." |
| Voice           | Active voice, addressing the reader as "you" | "Restart your device."                                     |
| Headings        | Sentence case, no full stops                 | "Reset your password"                                      |
| Page titles     | Start with a verb for how-to guides          | "How to Reset Your Password"                               |
| Spelling        | One spelling variant, used everywhere        | "Sign in" and "sign-in", never "log in"                    |
| Interface items | Bold the exact label                         | Select **Forgot Password**                                 |
| Sample data     | Use the `.example` domain                    | it-support@vctechnologies.example                          |

### Page Template for How-to Guides

1. Title
2. One-line introduction
3. Info hint with the key caveat
4. Metadata table (owner, type, version, last updated)
5. Before You Start
6. Steps (stepper)
7. Warnings
8. Troubleshooting (expandables)
9. Contact IT Support

### When to Use Each Block

| Block         | Use it for                                    |
| ------------- | --------------------------------------------- |
| Stepper       | Tasks where the order matters                 |
| Table         | Lookups and comparisons                       |
| Hint: info    | Helpful notes                                 |
| Hint: warning | Things that are easy to get wrong             |
| Hint: danger  | Actions that can cause harm or break policy   |
| Hint: success | A clear "you're done" message                 |
| Expandable    | Reference material most readers will not need |
| Tabs          | Content that differs by operating system      |

### Review Checklist

* [ ] The page follows the template
* [ ] All links open the right page
* [ ] No passwords or secrets appear in examples
* [ ] The version and last-updated date are current
* [ ] The page reads well on a phone
